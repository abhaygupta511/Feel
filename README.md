# FEEL — Music for Every Mood

A no-login, responsive mood-led music discovery website.

## Run
Open index.html in a modern browser or deploy this repository with GitHub Pages.

## Music source
FEEL uses the public Audius discovery API for independent music search and streaming. Availability and rights are controlled by Audius and each contributor. FEEL does not download or re-host tracks.

## Features
- Mood-based music discovery
- Free-text mood matching (English and Hinglish keywords)
- Audius search and trending
- Player controls: play, pause, previous, next, seek and volume
- Local audio file playback (device-only)
- Responsive dark violet interface
- No FEEL account or login required

## Notes
This project does not include a licensed catalogue of mainstream commercial music. Third-party source policies, availability and notices may change.
